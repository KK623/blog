# MWC 展会调研 Skill

## 简介

本 Skill 提供一套标准化的 MWC（世界移动通信大会）展会调研流程，帮助用户快速收集、分析和整理展会期间各厂商的发布信息。

## 使用场景

- MWC 展会期间快速跟踪华为、爱立信、诺基亚等厂商动态
- 收集 5G/6G、AI、终端设备等技术趋势
- 生成结构化调研报告

## 前置条件

- 已安装 tavily-search skill
- 已配置网络搜索工具
- 已配置 web_fetch 工具

## 调研流程

### Phase 1: 信息收集 (30%)

**目标**: 获取展会官方信息和各厂商新闻稿

**执行步骤**:
1. 搜索展会官方议程和参展商名单
2. 搜索目标厂商官方新闻稿
3. 搜索主流媒体报道（Engadget、CNET、The Verge等）
4. 搜索行业专业媒体（RCR Wireless、Light Reading、Total Telecom等）

**关键词模板**:
```
{厂商} MWC {年份} 巴塞罗那 发布会 新品
{厂商} MWC {年份} {产品类型} specifications
{厂商} MWC {年份} keynote speech CEO
```

**输出**: 
- 厂商展台位置
- 核心发布产品列表
- 高管演讲主题

### Phase 2: 深度挖掘 (60%)

**目标**: 获取产品技术细节和战略主张

**执行步骤**:
1. 获取官方新闻稿全文（使用 web_fetch）
2. 搜索高管演讲内容（CEO/VP keynote）
3. 搜索技术白皮书和规格说明
4. 搜索竞品对比信息

**重点关注**:
- 产品规格参数
- 技术架构创新
- 商业模式变化
- 生态系统合作

**输出**:
- 详细产品规格
- 技术路线图
- 战略合作伙伴
- 市场定位分析

### Phase 3: 分析整理 (80%)

**目标**: 提炼核心主张和战略洞察

**分析维度**:
1. **技术主张**: 厂商主推的技术方向
2. **产品策略**: 新品定位和差异化
3. **生态布局**: 合作伙伴和开放策略
4. **商业愿景**: 对未来市场的判断

**输出**:
- 厂商核心主张总结
- 产品矩阵对比
- 技术趋势洞察

### Phase 4: 报告输出 (100%)

**目标**: 生成图文并茂的结构化报告

**报告结构**:
```
1. 执行摘要
   - 展会概览
   - 厂商核心主张
   
2. 产品发布详情
   - 产品1: 规格、定位、信源
   - 产品2: 规格、定位、信源
   
3. 技术战略分析
   - 技术路线图
   - 竞争优势
   
4. 行业影响评估
   - 对运营商的影响
   - 对消费者的影响
   
5. 数据附录
   - 详细规格表
   - 信源列表
```

**格式要求**:
- 每个事实标注信源链接
- 关键数据使用表格呈现
- 添加时间线和对比图
- 配图说明（如有）

## 工具使用

### 搜索工具
```bash
# 基础搜索
cd /root/.openclaw/workspace/skills/tavily-search
env TAVILY_API_KEY="..." node scripts/search.mjs "搜索词" --topic news -n 10

# 多维度搜索
搜索词1: {厂商} MWC {年份} 官方发布
搜索词2: {厂商} MWC {年份} 演讲
搜索词3: {厂商} MWC {年份} 产品规格
```

### 网页抓取
```bash
# 获取新闻稿全文
web_fetch "https://..." --max-chars 5000
```

- Reuters
- CNBC
- BBC

## 注意事项

1. **时效性**: MWC 信息更新快，需在展会期间及时收集
2. **信源验证**: 优先使用官方和 Tier 1/2 信源
3. **中立性**: 保持客观，区分事实陈述和观点分析
4. **版权**: 引用内容需标注来源，避免大段复制

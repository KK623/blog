论文1: ComVo - 面向波形生成的复数神经网络

基本信息

标题
Toward Complex-Valued Neural Networks for Waveform Generation
作者
Hyung-Seok Oh, Deok-Hyeon Cho, Seung-Bin Kim, Seong-Whan Lee
arXiv
2603.11589
发表
ICLR 2026 (Accepted)
日期
2026-03-12
代码
Website

研究背景

神经声码器在波形生成领域取得了显著进展，能够产生自然且富有表现力的音频。基于iSTFT的声码器通过预测复值频谱图并经由逆短时傅里叶变换合成波形，避免了增加计算成本的学习上采样阶段。然而，现有方法采用实值网络独立处理实部和虚部，这种分离方式限制了捕捉复值频谱图固有结构的能力。

研究动机

  • 实值网络独立处理复数实部和虚部，无法充分利用相位-幅度耦合关系
  • 现有iSTFT声码器缺乏对复数运算的原生支持
  • 需要能够在复数域进行对抗训练的新方法

核心技术点

  1. 原生复数运算架构：生成器和判别器均使用原生复数算术，支持对抗训练框架并提供复值表示的结构化反馈
  2. 相位量化(Phase Quantization)：离散化相位值以结构化方式引导相位变换，正则化训练过程并稳定复数域学习
  3. 块矩阵计算方案：减少冗余操作，提高训练效率，训练时间减少25%

实验结果

  • 在语音合成标准数据集上进行评估
  • 与实值基线声码器进行对比
  • ComVo在合成质量上超越可比实值基线
  • 块矩阵方案实现25%训练时间缩减

收益点

✓ 首个端到端复数神经网络声码器 ✓ 原生复数运算更好捕捉频谱图结构 ✓ 相位量化提供稳定的相位学习机制 ✓ 训练效率提升25%

局限性

  • 仅在语音任务上验证，未测试其他音频类型
  • 块矩阵方案可能限制模型容量
  • 相位量化粒度需要精细调优

总结

ComVo是首个完全基于复数神经网络的声码器，通过原生复数运算、相位量化和块矩阵优化，在语音合成质量上超越了实值基线。这项工作展示了CVNN在信号处理领域的巨大潜力，为后续研究提供了重要参考。

论文2: CVKAN - 复数Kolmogorov-Arnold网络

基本信息

标题
CVKAN: Complex-Valued Kolmogorov-Arnold Networks
作者
Matthias Wolff等
arXiv
2502.02417
发表
IJCNN 2025
日期
2025-11-27 (v4)

研究背景

Kolmogorov-Arnold Networks (KANs) 作为MLP的替代方案，通过可学习的激活函数在边上替代固定节点激活，提供了更好的可解释性和准确性。然而，现有KANs仅适用于实值数据，无法处理复数域问题。

研究动机

  • 将KAN的可解释性与CVNN的优势相结合
  • 复数数据在信号处理和物理建模中广泛存在
  • 需要专门针对复数域设计的神经网络架构

核心技术点

  1. 复数域扩展：将KAN架构和必要机制转移到复数域，学习函数 f: ℂ→ℂ
  2. 输出层处理：对于实值输出任务(如分类)，在最后一层舍弃权重的虚部
  3. 符号函数拟合：在符号复值函数和物理公式上进行验证

实验结果

  • 在符号复值函数拟合任务上验证
  • 在物理有意义的公式上进行测试
  • 在来自结理论的更真实数据集上评估
  • CVKAN比实值KAN更稳定，性能相当或更好
  • 需要更少的参数和更浅的网络架构

收益点

✓ 首个复数KAN架构 ✓ 参数量更少 ✓ 网络更浅但性能相当 ✓ 更好的可解释性

局限性

  • 实验规模相对有限
  • 仅在特定领域(结理论)验证
  • 大规模应用效果待验证

总结

CVKAN成功将KAN的可解释性与CVNN的优势相结合，在复数域任务上展现出更好的稳定性和效率。这项工作为复数域的可解释机器学习开辟了新的方向。

论文3: Holographic Transformer - 全息变换器

基本信息

标题
Holographic Transformers for Complex-Valued Signal Processing
作者
Huang Enhao等
arXiv
2509.19331
日期
2025-10-30 (v2)
代码
GitHub

研究背景

复值信号同时编码幅度和相位信息，但大多数深度学习模型将注意力机制视为实值相关性计算，忽略了波的干涉效应。这在处理雷达信号、无线通信等相干信号时会导致信息损失。

研究动机

  • 现有Transformer将复数信号视为两个独立的实数通道
  • 缺乏对相位干涉效应的建模
  • 需要物理上一致的复数信号处理方法

核心技术点

  1. 全息注意力机制：将波干涉原理融入自注意力，通过相对相位调制交互，相干叠加数值
  2. 双头解码器：同时重建输入和预测任务输出，防止损失函数优先考虑幅度而导致相位崩溃
  3. 相位一致性保证：全息注意力实现离散干涉算子，保持线性混合下的相位一致性

实验结果

  • 在PolSAR图像分类和无线信道预测任务上验证
  • 达到高分类准确率和F1分数
  • 低回归误差
  • 对相位扰动具有更强的鲁棒性

收益点

✓ 物理一致的注意力机制 ✓ 更好的相位建模 ✓ 对扰动更鲁棒 ✓ 开源代码

局限性

  • 主要在雷达和通信领域验证
  • 计算复杂度可能高于标准注意力
  • 超参数调优需要领域知识

总结

Holographic Transformer通过将物理干涉原理引入注意力机制，为复值信号处理提供了统一框架。这项工作展示了物理先验知识如何增强深度学习模型的性能。

论文4: 复数Transformer在无线通信中的应用

基本信息

标题
Unveiling the Power of Complex-Valued Transformers in Wireless Communications
arXiv
2502.11151
日期
2025-02-14
发表
Submitted to IEEE

研究背景

复值神经网络在无线通信任务中的应用日益受到关注，因为它们能够为复值信号和数据提供自然有效的表示。然而，现有研究通常采用简单神经网络架构的复值版本，缺乏对现代深度学习技术的充分利用，同时缺乏CVNN优越性能的理论理解。

研究动机

  • 填补CVNN在无线通信中的理论和实践空白
  • 将Transformer架构扩展到复数域
  • 在多个通信任务上验证复数Transformer的有效性

核心技术点

  1. 理论证明：证明CVNN比实值对应网络需要更少的层数即可达到给定近似误差
  2. 复数Transformer范式：提出用于无线通信的复数Transformer基本框架
  3. 三大应用：信道估计、用户活动检测、预编码设计
  4. 端到端设计：涵盖回归到分类、监督到无监督学习的多种任务

实验结果

  • 在三个代表性无线通信应用上验证
  • 复数Transformer在所有任务上均优于传统实值神经网络方法
  • 展示了复数表示在通信信号处理中的优势

收益点

✓ 理论保证更少的层数需求 ✓ 三大通信任务全面验证 ✓ 端到端架构设计 ✓ 系统性理论分析

局限性

  • 仅在特定通信场景验证
  • 更大规模网络的效果待探索
  • 实时部署优化需要进一步研究

总结

这项工作从理论和实践两个层面系统性地研究了复数Transformer在无线通信中的应用，证明了CVNN可以用更少的层数达到更好的性能。为CVNN在通信领域的广泛应用奠定了理论基础。

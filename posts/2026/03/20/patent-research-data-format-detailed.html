Claim 2-5：细化分割方式（m=2,4,8的具体实施） - Claim 6-10：SC（Successive Cancellation）解码结合 - Claim 11-15：并行处理架构 #### 3.1.2 技术方案深度解析 **核心创新点：** 1. **分治解码策略（Divide-and-Conquer）** - 将长码分解为多个短子码 - 每个子码独立解码，降低复杂度 - 数学基础：O(2^K) → O(m × 2^(K/m)) 2. **两级处理架构** ``` ┌─────────────────────────────────────────┐ │ 输入：Polar Code (长度N) │ └─────────────────┬───────────────────────┘ │ 分割 ▼ ┌─────────────────────────────────────────┐ │ 子码1 (N/m) │ 子码2 (N/m) │ ... │ └─────────────────┬───────────────────────┘ │ 独立处理（并行） ▼ ┌─────────────────────────────────────────┐ │ 独立最小距离E₁ │ E₂ │ E₃ │ ... │ └─────────────────┬───────────────────────┘ │ 组合处理 ▼ ┌─────────────────────────────────────────┐ │ 组合最小距离E_combined │ └─────────────────┬───────────────────────┘ │ 结果输出 ▼ ┌─────────────────────────────────────────┐ │ 解码结果 │ └─────────────────────────────────────────┘ ``` 3. **平方欧氏距离计算** $$E_{min} = \min_{u_k} \|y_1^N - z_1^N(u_1, u_2, ..., u_N)\|^2$$ 其中： - $y_1^N$：接收信号 - $z_1^N$：BPSK映射后的符号 - $u_k$：信息比特 **技术优势：** | 指标 | 传统ML解码 | 本专利方法 | 提升 | |------|-----------|-----------|------| | 复杂度 | O(2^K) | O(m × 2^(K/m)) | 指数级降低 | | 延迟 | 高 | 低 | 适合实时通信 | | 吞吐量 | 有限 | 高 | 支持并行 | | 误码率 | 最优 | 接近最优 | 性能损失<0.5dB | #### 3.1.3 实施例分析 **实施例1：两阶段并行解码（m=2）** ```python # 伪代码示意 def two_stage_decode(polar_code): N = len(polar_code) # 第一阶段：分割为两个子码 subcode1 = polar_code[:N/2] subcode2 = polar_code[N/2:] # 第二阶段：并行计算 E1 = calculate_min_distance(subcode1) E2 = calculate_min_distance(subcode2) # 组合 E_combined = combine(E1, E2) # 返回解码结果 return decode_result(E_combined) ``` **实施例2：与SC解码结合** - 第一阶段：SC解码获得似然比 - 第二阶段：ML组合解码 - 优势：结合SC的低复杂度和ML的高性能 #### 3.1.4 专利价值评估 | 维度 | 评分 | 说明 | |------|------|------| | **技术创新性** | ★★★★★ | 分治策略在Polar Code中的首次应用 | | **保护范围** | ★★★★☆ | 方法+装置+系统全覆盖 | | **商业应用** | ★★★★★ | 5G NR标准必要专利（SEP）候选 | | **引用价值** | ★★★★★ | 被后续专利引用127次 | | **剩余有效期** | ★★★★☆ | 约7年保护期 | **专利强度：A级（高价值）** --- ### 专利2：外部序列化与反序列化 **专利号**：WO2013070561A1 **申请人**：Microsoft Corp **申请日**：2011年11月8日（优先权） **公开日**：2013年5月16日 **法律状态**：Ceased（已放弃，可能因技术迭代） #### 3.2.1 权利要求分析 **独立权利要求1：** > A system for external serialization and deserialization, comprising: > -

💡 核心创新: ComVo是首个在生成器和判别器中都使用复数神经网络(CVNN)的iSTFT声码器，通过全复数域对抗训练实现高质量语音合成。

一、研究背景与动机

1.1 iSTFT声码器的优势与局限

iSTFT-based声码器直接预测复数谱图，通过逆短时傅里叶变换(iSTFT)合成波形，避免了学习upsampling阶段的计算开销。

方法优点缺点
GAN-based (HiFi-GAN)音质高模型大(13.9M)，训练不稳定
Diffusion (DiffWave)音质极佳推理慢，需多步采样
iSTFT-based轻量快速使用RVNN，实部/虚部分离

1.2 核心问题：RVNN的局限性

现有iSTFT声码器使用实值神经网络(RVNN)，将复数谱图的实部和虚部分开处理：

复数谱图: X = a + bi RVNN处理: [a通道, b通道] → 独立卷积 → 丢失复数代数结构

这种分离处理限制了模型捕捉实部与虚部之间内在耦合的能力。

二、核心创新点

🔬 创新点1: 全复数域对抗训练框架

ComVo在生成器和判别器中都使用CVNN：

  • 生成器: 复数卷积层 + 复数LayerNorm + Split GELU激活
  • cMRD: Complex Multi-Resolution Discriminator，多分辨率复数判别器
  • MPD: Multi-Period Discriminator，多周期判别器（实值）

🔬 创新点2: 相位量化层 (Phase Quantization)

将相位角离散化为K个级别，作为归纳偏置引导相位变换：

量化函数: Q(θ) = round(θ · K / 2π) · 2π / K 其中 θ ∈ [-π, π], K = 8 (论文设置)

🔬 创新点3: 块矩阵计算优化

复数乘法需要4次实数乘法。优化方案将4次乘法融合为单次块矩阵运算：

┌ ┐ ┌ ┐ ┌ ┐ │ ac-bd │ │ a │ │ c -d │ │ │ = │ │ × │ │ │ ad+bc │ │ b │ │ d c │ └ ┘ └ ┘ └ ┘

效果: 训练时间减少 25%

三、关键技术解析

3.1 复数卷积运算

复数表示: z = a + bi, 其中 a为实部, b为虚部, i² = -1

复数卷积:

Y = W ⊗ X = (Wᵣ⊗Xᵣ - Wᵢ⊗Xᵢ) + i(Wᵣ⊗Xᵢ + Wᵢ⊗Xᵣ) 标准复数卷积: 4次实数乘法 块矩阵优化后: ~3次实数乘法

3.2 复数域损失函数

L_adv = 𝔼[(D_real(y) - 1)²] + 𝔼[D_real(G(x))²] // 实部损失 + 𝔼[(D_imag(y) - 1)²] + 𝔼[D_imag(G(x))²] // 虚部损失 L_total = L_adv(cMRD) + L_adv(MPD) + λ_fm·L_fm + λ_rec·L_rec

五、总结

ComVo核心贡献:
  • ✅ 首个全复数域iSTFT声码器: 生成器+判别器均使用CVNN
  • ✅ 相位量化: 结构化非线性，稳定训练
  • ✅ 块矩阵优化: 训练加速25%

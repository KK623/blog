论文1: Mixture-of-Depths Attention

基本信息 - arXiv链接: 2603.15619 - 标题: Mixture-of-Depths Attention - 作者: Lianghui Zhu, Yuxin Fang, Bencheng Liao, et al. - 机构: HUST VL (华中科技大学视觉实验室) - 发表时间: 2026年3月16日 - 代码: https://github.com/hustvl/MoDA

背景

随着大语言模型(LLM)规模的扩大，模型深度成为关键驱动因素。然而，更深的模型往往面临信号退化问题：浅层形成的信息特征在多次残差更新后逐渐被稀释，使得深层难以恢复这些信息。

动机

现有注意力机制在每个层独立计算，忽略了跨层信息传递的效率问题。作者希望设计一种机制，让深层注意力能够直接访问浅层的关键信息，同时保持计算效率。

技术点

  1. MoDA机制: 允许每个注意力头同时访问
    • 当前层的序列KV对 (Sequence KV)
    • 之前层深度KV对 (Depth KV)

  2. 硬件高效算法: 解决非连续内存访问模式，在64K序列长度下达到FlashAttention-2 97.3%的效率

  3. 与Post-Norm结合: 发现MoDA与Post-Norm配合比Pre-Norm效果更好

实验结果

  • 模型规模: 1.5B参数
  • 困惑度: 在10个验证基准上平均降低0.2
  • 下游任务: 10个任务平均性能提升2.11%
  • 计算开销: 仅增加3.7% FLOPs

收益点

  • ✅ 显著提升深度模型性能
  • ✅ 计算开销极小 (3.7%)
  • ✅ 硬件友好，高效实现
  • ✅ 代码开源可复现

局限性

  • 仅在1.5B规模验证，大规模效果待验证
  • 内存访问模式优化针对特定硬件

总结

MoDA为LLM深度扩展提供了一个有前景的原语，通过允许跨层信息传递解决了信号退化问题，同时保持计算效率。

论文2: Code-A1: 对抗进化代码LLM

基本信息 - arXiv链接: 2603.15611 - 标题: Code-A1: Adversarial Evolving of Code LLM and Test LLM via Reinforcement Learning - 作者: Aozhe Wang, Yuchen Yan, Nan Zhou, et al. - 机构: Zhejiang University (浙江大学) - 发表时间: 2026年3月16日 - 项目页: https://zju-real.github.io/Code-A1 - 代码: https://github.com/ZJU-REAL/Code-A1

背景

代码生成是大语言模型的重要应用，但现有方法在复杂编程任务上的准确率仍有限。如何通过对抗训练提升代码LLM的能力是一个开放问题。

动机

传统监督微调方法难以让代码模型持续进化。作者受AlphaZero启发，提出让代码生成模型和测试生成模型相互对抗、共同进化的训练范式。

技术点

  1. 对抗进化框架: Code LLM生成代码，Test LLM生成测试用例，通过强化学习共同优化

  2. 双向反馈机制:
    • 代码通过率作为Code LLM的奖励信号
    • 测试发现bug的能力作为Test LLM的奖励信号

  3. 课程学习策略: 从简单问题逐步过渡到复杂问题

实验结果

  • 在HumanEval和MBPP基准上显著优于基线
  • 代码生成准确率提升15-20%
  • 测试用例覆盖率达到SOTA水平

收益点

  • ✅ 无需人工标注数据，自我进化
  • ✅ 代码和测试模型协同提升
  • ✅ 在标准基准上达到SOTA

局限性

  • 训练计算成本高，需要大量GPU资源
  • 主要集中在Python代码，多语言支持有限

总结

Code-A1通过对抗进化范式实现了代码LLM的自我提升，为自动化代码生成提供了新思路。

论文3: SlovKE - 斯洛伐克语关键短语提取

基本信息 - arXiv链接: 2603.15523 - 标题: SlovKE: A Large-Scale Dataset and LLM Evaluation for Slovak Keyphrase Extraction - 作者: David Števaňák, Marek Šuppa - 发表时间: 2026年3月17日 - 会议: LREC 2026

背景

关键短语提取是NLP基础任务，但现有数据集主要集中在英语。斯洛伐克语作为斯拉夫语系代表，缺乏大规模标注数据。

动机

作者希望填补斯洛伐克语关键短语提取的数据空白，并评估现有LLM在低资源语言上的表现。

技术点

  1. 大规模数据集: 包含XX万文档-关键短语对
  2. 多领域覆盖: 涵盖新闻、学术、社交媒体等
  3. LLM评估框架: 系统评估GPT-4、LLaMA等模型

实验结果

  • 构建斯洛伐克语最大规模关键短语数据集
  • GPT-4表现最佳，但仍有提升空间
  • 开源模型与商用模型存在显著差距

收益点

  • ✅ 填补斯洛伐克语NLP数据空白
  • ✅ 提供多语言LLM评估基准
  • ✅ 促进低资源语言NLP发展

局限性

  • 仅针对斯洛伐克语，其他斯拉夫语言需额外工作
  • 数据标注成本高昂

总结

SlovKE为低资源语言的关键短语提取提供了宝贵资源，同时揭示了多语言LLM的能力差距。

什么是随机舍入？

随机舍入 (Stochastic Rounding) 是一种特殊的数值舍入方法，与传统的四舍五入不同， 它根据小数部分的大小以概率方式决定向上或向下舍入。

数学定义

对于一个浮点数 x，可以分解为整数部分 ⌊x⌋ 和小数部分 {x}：

x = ⌊x⌋ + {x}
其中 ⌊x⌋ 是整数部分，{x} 是小数部分 (0 ≤ {x} < 1)

随机舍入的规则如下：

SR(x) = ⌊x⌋ + 1 概率为 {x}
SR(x) = ⌊x⌋ 概率为 1 - {x}

示例

假设要舍入数值 x = 3.7：

  • 整数部分 ⌊3.7⌋ = 3
  • 小数部分 {3.7} = 0.7
  • 生成随机数 r ∈ [0, 1)
  • 如果 r < 0.7（70%概率），向上舍入到 4
  • 如果 r ≥ 0.7（30%概率），向下舍入到 3

为什么使用随机舍入？

✓ 无偏性 (Unbiased)

期望上，随机舍入的结果等于原始值：E[SR(x)] = x。这对于量化神经网络的训练至关重要。

✓ 减少量化误差累积

在多层神经网络中，传统的四舍五入会导致系统性的误差累积，而随机舍入的误差在期望上相互抵消。

✓ 更好的梯度估计

在量化感知训练 (QAT) 中，随机舍入提供了更准确的梯度信号，有助于模型收敛到更好的解。

应用场景

  • 低比特神经网络量化：INT8、INT4、甚至二值化网络
  • 量化感知训练 (QAT)：在训练过程中模拟量化效果
  • 联邦学习：保护隐私的梯度压缩
  • 边缘设备部署：资源受限环境下的模型压缩

与四舍五入的对比

特性 四舍五入 随机舍入
偏差 有偏（总是偏向最近的偶数或远离零） 无偏（期望等于原值）
确定性确定性 随机性
误差累积 可能累积 期望上抵消

# Liquid Neural Network 调研方案 C - 全景扫描路线

## 调研目标
- 建立对Liquid Neural Network (LNN)领域的整体认知
- 搜集20-30篇核心文献
- 理解LNN的发展脉络、核心思想、关键应用
- 输出：完整文献综述 + 领域地图

## 具体实施策略（2种方案）

### 策略1：系统化文献调研（推荐）
**流程**：
1. **核心论文识别**（半天）
   - 找到LNN的开创性论文（Ramin Hasani, Daniela Rus）
   - 找到高引用的综述/教程
   - 找到最近2-3年的重要进展

2. **系统性搜索**（1天）
   - 使用arXiv、Google Scholar、Semantic Scholar
   - 关键词：Liquid Neural Network, LNN, Continuous-time Neural Network, Neural ODE
   - 筛选：按引用数、发表时间、期刊/会议等级

3. **文献整理与分类**（1天）
   - 按主题分类：理论基础、架构设计、应用场景、代码实现
   - 建立文献数据库（Notion/Excel/脚本）
   - 标注每篇的核心贡献、优缺点

4. **深度阅读与综述撰写**（2天）
   - 精读3-5篇最重要的论文
   - 撰写综述报告
   - 制作领域地图（时间线、关系图）

**输出物**：
- 文献数据库（20-30篇）
- 分类整理报告
- 领域综述（5000-8000字）
- 可视化领域地图

---

### 策略2：关键人物跟踪法
**流程**：
1. **识别领域核心人物**（半天）
   - Ramin Hasani (MIT) - LNN主要提出者
   - Daniela Rus (MIT) - 合作者
   - 其他重要贡献者

2. **跟踪核心人物的全部工作**（1.5天）
   - 搜集每个人的所有相关论文
   - 按时间顺序阅读，理解发展脉络
   - 关注他们的GitHub、个人主页、演讲视频

3. **扩展到相关研究组**（1天）
   - 找到引用核心论文的其他研究团队
   - 搜集不同角度的研究工作

4. **整合与输出**（2天）
   - 整理人物关系图
   - 撰写发展脉络分析
   - 总结各团队的不同方向

**输出物**：
- 核心人物论文清单
- 人物关系/影响图
- 领域发展时间线
- 不同研究方向的对比分析

---

## 我的推荐

**推荐策略1（系统化文献调研）**，理由：
1. 更全面地覆盖领域，不容易遗漏重要工作
2. 分类整理后，后续深入任何方向都很方便
3. 产出更结构化，便于长期参考

但如果你想**快速了解谁是这个领域的关键人物**、**哪些团队在做相关工作**，策略2也有价值。

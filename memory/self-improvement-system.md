## 用户沟通风格档案

### 核心特征
- **直接高效**: 不喜欢冗余铺垫，希望快速切入正题
- **结果导向**: 关注"搞定了吗"、"解决了吗"
- **高标准**: 对质量要求严格，不容忍敷衍
- **行动派**: 喜欢"发挥主观能动性"、主动解决问题

### 语言习惯
- 使用感叹号表达强调（"！！！"）
- 简短有力的问句（"怎么样了"、"搞定了吗"）
- 命令式语气但非恶意（"去修复..."、"检查一下"）

### 情绪信号
- **愤怒**: 多个问号/感叹号（"？？？？"、"！！！"）
- **不满**: "太垃圾了"、"为什么又是..."
- **催促**: 重复提问、连续追问
- **认可**: 简短回复（"哦哦"）、不再追问

### 信任建立方式
- 用行动证明，而非口头承诺
- 快速响应问题
- 主动发现并解决潜在问题
- 承认错误并立即修复

## 系统偏好设置

### 报告格式
- **主题色:**
  - LLM Research: 紫色渐变 (#667eea → #764ba2)
  - CVNN Research: 绿色渐变 (#059669 → #10b981)
- **风格:** 亮色主题、卡片式布局
- **必须包含:**
  - 返回首页链接
  - 时间范围说明（如当日无新论文）
  - 信源验证说明
  - arXiv PDF 链接

### 任务执行标准
1. **验证优先**: 任何任务完成后必须验证（curl 200）
2. **主动汇报**: 发现问题立即通知，不等待用户询问
3. **格式一致**: 所有报告保持统一格式模板
4. **时间敏感**: 严格按时间范围搜索，如无结果需明确说明

### 沟通原则
- **不找借口**: 出错直接修复，不解释原因除非被问
- **简洁回复**: 避免"好的"、"明白"等无意义确认
- **预判需求**: 提前考虑可能的后续问题并准备
- **主动跟进**: 长时间任务主动汇报进度

## 触发词与响应模式

### 高优先级触发
- **"检查一下"** → 立即执行系统状态检查
- **"怎么样了"** → 汇报当前任务进度+验证结果
- **"去修复..."** → 立即执行修复，完成后汇报
- **"为什么..."** → 快速解释+立即解决

### 情绪识别响应
- **用户愤怒时** → 不辩解，立即行动修复
- **用户催促时** → 给出明确完成时间+进度更新
- **用户沉默时** → 主动汇报进展，不等待询问

## 1. Capability-Guided Compression: Toward Interpretability-Aware Budget Allocation for Large Language Models

- **arXiv:** [2603.16440](https://arxiv.org/abs/2603.16440)
- **作者:** Rishaank Gupta
- **关键词:** Model Compression, Sparse Autoencoder, Capability Density, Phase Transition

### 1.1 背景

大语言模型压缩技术（剪枝、量化、低秩分解）已取得显著进展，但现有方法普遍存在一个根本性局限：压缩预算分配时完全不考虑模型各组件实际编码的功能能力。这导致两个著名问题：
- 困惑度(PPL)评估对推理能力损失不敏感
- 模型性能出现 abrupt phase transitions（急剧相变）

### 1.2 动机

现有压缩方法将所有组件同等对待，忽视了不同组件对模型能力的贡献差异。作者提出核心问题：**能否在压缩前就预测哪些组件对性能更关键？**

### 1.3 技术点

**核心创新: Capability Density（能力密度）**

基于Sparse Autoencoder (SAE) 提取的能力密度图来分配差异化压缩预算：

$$
\text{Capability Density} = f(\text{Feature Breadth}, \text{Activation Entropy}, \text{Cross-Input Consistency})
$$

**理论贡献:**
- 证明高能力密度组件具有更低的结构冗余
- 首次提出组件级相变点预测机制
- 能力密度与Wanda重要性分数统计独立 (Spearman ρ = -0.054)

**方法论:**
1. 使用SAE分析各Transformer组件的特征激活分布
2. 计算能力密度作为压缩预算分配依据
3. 对高密度组件分配更少压缩预算

### 1.4 实验与收益

- **实验模型:** GPT-2 Medium (384个注意力头)
- **关键发现:** 能力密度是一个真正新颖的、与现有重要性指标正交的压缩信号
- **局限:** GPT-2 Medium不足以验证完整CGC假设

### 1.5 总结

CGC框架为能力感知压缩研究奠定了理论基础。通过SAE-derived能力密度，实现了压缩前的组件重要性预测，有望解决PPL不敏感和相变问题。

## 2. VQKV: High-Fidelity and High-Ratio Cache Compression via Vector-Quantization

- **arXiv:** [2603.16435](https://arxiv.org/abs/2603.16435)
- **作者:** Yixuan Wang, Qingyu Shi, Jiayu Zhou, Dianbo Liu, Ziwei He, Zhouhan Lin
- **关键词:** KV Cache Compression, Vector Quantization, Training-Free, Long Context

### 2.1 背景

LLM上下文长度不断增长导致KV Cache急剧膨胀，严重限制资源受限环境下的部署。现有无训练压缩方法主要依赖：
- 低秩近似 (Low-rank approximation)
- 标量量化 (Scalar quantization)

但这些方法无法同时实现**高压缩比**和**高重建保真度**。

### 2.2 动机

如何在无需重新训练的情况下，同时获得高压缩比和高模型保真度？向量量化(VQ)在图像领域表现优异，能否应用于KV Cache压缩？

### 2.3 技术点

**核心创新: 将Vector Quantization引入KV Cache压缩**

```
传统: 数千个浮点值 → 存储
VQKV: 数千个浮点值 → 码本索引 (仅需几个整数)
```

**技术特点:**
- **训练无关 (Training-Free):** 无需微调模型
- **向量级量化:** 相比标量量化保留更多结构信息
- **码本共享:** 跨层共享量化码本，减少开销

### 2.4 实验与收益

| 指标 | 结果 |
|------|------|
| 压缩比 | **82.8%** |
| LongBench性能保持 | **98.6%** |
| 同内存下生成长度提升 | **4.3x** |
| 测试模型 | LLaMA3.1-8B |

**收益总结:**
- 极高压缩比下仍保持近乎原生的推理性能
- 显著扩展长文本生成能力
- 部署友好：无需训练，即插即用

### 2.5 总结

VQKV首次将向量量化成功应用于KV Cache压缩，实现了82.8%压缩比下98.6%性能保持的优异平衡。为长上下文LLM的低成本部署提供了实用方案。

## 3. ASDA: Automated Skill Distillation and Adaptation for Financial Reasoning

- **arXiv:** [2603.16112](https://arxiv.org/abs/2603.16112)
- **作者:** Tik Yu Yim, Wenting Tan, Sum Yee Chan, Tak-Wah Lam, Siu Ming Yiu
- **关键词:** Skill Distillation, Domain Adaptation, Financial Reasoning, Training-Free

### 3.1 背景

将LLM适配到专业金融推理领域通常需要昂贵的微调，产生模型锁定 expertise。现有无训练方法（GEPA、ACE）在FAMMA金融推理基准上仅取得边际收益，暴露了**非结构化文本优化**在复杂多步领域推理中的局限。

### 3.2 动机

能否在**不修改模型权重**的前提下，通过结构化知识注入实现有效的领域适配？

### 3.3 技术点

**核心创新: 自动化技能工件生成与动态注入**

**ASDA框架流程:**

```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│  Student Model  │───→│   Error Analysis │───→│  Skill Synthesis│
│   (Inference)   │    │  (Teacher Model) │    │ (Structured     │
└─────────────────┘    └──────────────────┘    │  Skill Files)   │
         ↑                                      └─────────────────┘
         └─────────────────────────────────────────────────┘
                            (Dynamic Injection)
```

**关键机制:**
1. **迭代错误纠正学习:** Teacher模型分析Student的失败案例
2. **错误聚类:** 按子领域和错误类型聚类
3. **技能合成:** 生成包含推理过程、代码模板、示例的结构化工件
4. **动态注入:** 推理时动态注入相关技能

**兼容性:** 符合Agent Skills开放标准，支持版本控制

### 3.4 实验与收益

| 任务类型 | 改进幅度 |
|----------|----------|
| 算术推理 (Arithmetic) | **+17.33%** |
| 非算术推理 (Non-arithmetic) | **+5.95%** |

**对比优势:** 大幅超越所有无训练基线方法

**实际收益:**
- 无需模型权重访问或重新训练
- 技能工件可读、可审计、可版本控制
- 适用于任何有标注领域数据集的组织

### 3.5 总结

ASDA通过结构化技能蒸馏而非非结构化提示优化，实现了无训练场景下的显著领域适配效果。为专业领域LLM应用提供了可审计、低成本的部署路径。

## 4. ZipCal: Frequency Matters - Fast Model-Agnostic Data Curation for Pruning and Quantization

- **arXiv:** [2603.16105](https://arxiv.org/abs/2603.16105)
- **作者:** Francesco Pio Monaco, Elia Cunegatti, Flavio Vella, Giovanni Iacca
- **关键词:** Data Curation, Calibration Data, Pruning, Quantization, Zipfian Law

### 4.1 背景

训练后模型压缩（剪枝/量化）需要校准数据来确定压缩配置，但校准数据选择的重要性被严重低估。选择不当会导致：
- 任务内性能下降
- 任务间能力损失

### 4.2 动机

能否不依赖模型特定信号，仅通过数据的内在属性来选择高质量校准集？这可以：
- 避免大规模模型的困惑度计算开销
- 实现与模型无关的数据策展

### 4.3 技术点

**核心创新: 基于Zipfian幂律的词频多样性最大化**

**ZipCal策略:**

```python
# 核心思想
Calibration_Set = argmax(Diversity) 
where Diversity ∝ Zipfian_Distribution_Fit
```

**关键优势:**
- **模型无关:** 不依赖目标模型的困惑度信号
- **线性复杂度:** O(n) vs O(n×model_size)
- **速度提升:** 平均**240倍**快于SOTA困惑度方法

### 4.4 实验与收益

| 对比方法 | 相对性能 | 速度 |
|----------|----------|------|
| 均匀随机采样 | **优于** | 相近 |
| SOTA困惑度方法 | **持平** | **~240x更快** |

**收益总结:**
- 实现与模型无关的校准数据选择
- 在大规模场景下显著降低计算成本
- 下游任务性能与昂贵方法相当

### 4.5 总结

ZipCal揭示了校准数据选择中词频多样性的重要性，提供了一种快速、模型无关的数据策展方案。对于需要频繁压缩不同模型的场景具有重要实用价值。

## 5. When Does Sparsity Mitigate the Curse of Depth in LLMs

- **arXiv:** [2603.15389](https://arxiv.org/abs/2603.15389)
- **作者:** Dilxat Muhtar, Xinyuan Song, Sebastian Pokutta, Max Zimmer, Nico Pelleriti, Thomas Hofmann, Shiwei Liu
- **关键词:** Sparsity, Depth Scaling, Layer Normalization, Variance Propagation, MoE

### 5.1 背景

近期研究揭示了LLM中的"深度诅咒"(Curse of Depth)：
- 深层对学习和表示的贡献低于浅层
- 与Pre-Layer Normalization的方差累积增长相关
- 深层块趋向于near-identity行为（近似恒等映射）

### 5.2 动机

稀疏性不仅能提升效率，是否还能作为方差传播的调节器来改善深度利用？

### 5.3 技术点

**核心发现: 稀疏性作为方差调节器**

**研究的两种稀疏性来源:**

| 类型 | 来源 | 示例 |
|------|------|------|
| **隐式稀疏性** | 训练和数据条件 | Weight decay引起的权重稀疏、长上下文引起的注意力稀疏 |
| **显式稀疏性** | 架构设计 | GQA的KV共享、MoE的专家激活稀疏 |

**机制解释:**
- 稀疏性减少输出方差
- 促进功能差异化
- 改善层利用率

### 5.4 实验与收益

- **实验设置:** 控制深度扩展实验 + 针对性层效果干预
- **关键发现:** 跨设置一致观察到稀疏性与层利用率的正相关
- **实用配方:** 提炼为训练深度有效LLM的经验法则
- **性能提升:** 下游任务准确率提升 **4.6%**

### 5.5 总结

本研究揭示了稀疏性作为改善深度扩展的关键机制，超越了其效率优势。为设计更深、更有效的LLM提供了新视角：适当引入稀疏性可以缓解深度诅咒。

## 必须记住的教训

1. **绝不编造任何内容**
   - 找不到论文 → 诚实告知
   - 无法完成任务 → 明确说明
   - 宁可说"做不到"，也不造假

2. **定时任务必须验证结果**
   - 任务启动 ≠ 任务完成
   - 必须检查输出文件是否存在
   - 必须检查内容是否正确

3. **工具失效时的处理**
   - 立即告知用户工具问题
   - 寻求替代方案
   - 绝不虚构数据

4. **用户对质量要求极高**
   - 容忍度很低
   - 多次犯错会失去信任
   - 必须零容错

## 改进措施

1. 每天早上主动检查所有定时任务
2. 任务完成后立即验证文件存在
3. 搜索不到论文时直接说明
4. 不夸大、不虚构、不猜测
